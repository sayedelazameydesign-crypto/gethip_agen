# Extension System

توسعة الوكيل تتم خارج النواة عبر `@agent/extension-system`. الإضافة تنفذ `IPlugin`، وتسجل المهام والاستراتيجيات عند التهيئة. كل مهمة تحمل مخطط Zod ومستوى موافقة؛ لا يُسمح بتنفيذها قبل المرور عبر Approval Gateway. ملفات `policies/` تُقرأ بصيغ JSON وYAML وتُمرر للسياق دون تضمين أسرار.
